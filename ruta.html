> Temas de Estudio por Nivel _

Despliega cada nivel para ver los temas específicos, herramientas y metas prácticas. Marca los temas a medida que avanzas.

Fundamentos de Computación

Redes (OBLIGATORIO)

Linux Básico

Meta Práctica

Montar una máquina virtual con Kali Linux o Ubuntu, navegar completamente por terminal sin usar interfaz gráfica, y entender un diagrama de red básico.

VirtualBox, Wireshark, Kali Linux

Python para Seguridad

Bash Scripting

PowerShell Básico

Meta Práctica

Escribir un script en Python que escanee puertos TCP usando sockets, automatizar una tarea repetitiva de Linux con Bash, y hacer una petición HTTP procesando la respuesta en Python.

VS Code, Python 3, pip

Metodología del Pentesting

Escaneo y Enumeración

Explotación Básica

Meta Práctica

Completar 20 máquinas fáciles en TryHackMe o Hack The Box, obtener tu primera reverse shell de forma manual (sin Metasploit), y entender la diferencia entre un exploit público y un CVE.

Nmap, Metasploit, Burp Suite Community, Gobuster, Netcat

Linux Privilege Escalation

Windows Privilege Escalation

Meta Práctica

Completar 30-40 máquinas de dificultad media, escalar privilegios en al menos 10 máquinas Linux y 10 Windows, hacer privesc sin herramientas automáticas (LinPEAS/WinPEAS) al menos una vez para entender el proceso manual.

LinPEAS, WinPEAS, PowerUp, PrivescCheck

Fundamentos de AD

Protocolos y Autenticación

Ataques Avanzados

Meta Práctica

Completar 10-15 laboratorios de AD completos, obtener Domain Admin desde un usuario sin privilegios iniciales, realizar un ataque DCSync y entender qué información se extrae (hashes, historial de contraseñas).

BloodHound, Neo4j, Impacket, CrackMapExec, Rubeus, Mimikatz

Pivoting

Movimiento Lateral

Exfiltración de Credenciales

Meta Práctica

Pivotar desde una red DMZ a otra interna en un laboratorio de AD, conseguir credenciales válidas con Responder en un entorno controlado, moverse lateralmente entre al menos 3 máquinas usando técnicas distintas, montar un laboratorio casero con 2 redes internas y practicar tunneling.

Chisel, Ligolo-ng, Proxychains, Responder, Impacket, CrackMapExec

Persistencia Linux

Persistencia Windows

Command & Control (C2)

Meta Práctica

Mantener acceso persistente en una máquina comprometida más de 24 horas sin ser detectado, implementar al menos 3 mecanismos de persistencia distintos (uno en Linux, dos en Windows), montar una infraestructura C2 básica (Sliver o Havoc) y conectar un agente desde una máquina virtual.

Metasploit, Sliver, Havoc, Empire, Netcat, Ncat

Evasión AV/EDR

Técnicas de Evasión

Evasión de Red

Meta Práctica

Crear un payload que evada Windows Defender sin herramientas comerciales, bypassear AMSI de al menos 2 formas distintas, hacer exfiltración de datos usando DNS en un entorno de laboratorio, detectar qué genera Sysmon al ejecutar distintos ataques.

MSFvenom, Veil Framework, Shellter, DefenderCheck, ThreatCheck

OSINT (Open Source Intelligence)

Ingeniería Social

Meta Práctica

Hacer un informe OSINT completo de ti mismo (footprint personal), encontrar subdominios, tecnologías y empleados de una empresa pública usando solo herramientas gratuitas, montar una campaña de phishing en un laboratorio con Gophish, clonar un sitio web con SET y capturar credenciales en local.

Maltego CE, theHarvester, Shodan, Sublist3r, ExifTool, SET, Gophish

Fundamentos Forenses

Análisis de Sistemas

Memoria y Red

Meta Práctica Forense

Crear una imagen forense de un disco y analizarla con Autopsy, analizar un volcado de memoria con Volatility y encontrar un proceso malicioso, reconstruir una sesión HTTP desde un archivo .pcap, analizar un malware conocido con PEStudio y documentar los hallazgos.

Respuesta a Incidentes (IR)

Autopsy, FTK Imager, Volatility 3, Wireshark, NetworkMiner, PEStudio, Ghidra, Splunk
